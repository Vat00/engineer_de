# Локальный Python ETL-конвейер данных

Учебный проект по созданию автоматизированного процесса извлечения, трансформации и загрузки (ETL) данных о продажах.

## 🚀 Используемые технологии
* **Python 3.13** (обработка, очистка данных)
* **Pandas** (анализ и манипуляция DataFrame)
* **SQLAlchemy & Psycopg2** (взаимодействие с базой данных)
* **PostgreSQL** (хранилище данных)
* **Docker & Docker Compose** (изолированное развертывание БД)

## 🛠️ Как это устроено
1. **Extract (Извлечение):** Программа берет сырые структурированные данные о товарах.
2. **Transform (Трансформация):** Удаляются лишние пробелы в именах продуктов методами векторизованной обработки строк Pandas.
3. **Load (Загрузка):** Данные инкрементально дописываются (метод `append`) в реляционную таблицу PostgreSQL. Безопасность доступов реализована через переменные окружения (`.env`).

## 💻 Инструкция по запуску проекта

### 1. Подготовка окружения
Клонируйте проект и перейдите в его директорию. Создайте файл `.env` в корневой папке и укажите настройки базы данных:
```env
DB_USER=admin
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5434
DB_NAME=engineer_db
```

### 2. Запуск базы данных в Docker
Поднимите контейнер с PostgreSQL одной командой из папки проекта:
```bash
docker-compose up -d
```

### 3. Запуск ETL-скрипта
Установите зависимости и запустите код:
```bash
pip install pandas sqlalchemy psycopg2 python-dotenv
python load_data.py
```
